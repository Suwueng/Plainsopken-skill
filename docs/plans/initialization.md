## 目标与验收

建立可持续优化 Plainspoken 的最小本地工程：开发资料与运行资料分离，输入和验收条件分离，固定被测源码，记录真实输出和判断，检查公开候选与历史隐私。默认不联网调用模型 API，不安装或发布。

验收包括：原安装测试不退化；新增异常输入测试可阻止伪通过和文件逃逸；合成用例可完成 prepare、执行、评审、report；公开候选无已知私人标识；历史问题明确阻断；词库与许可原文件不变。

## 决定

- 沿用标准库和现有安装工具，不建立服务、调度器或模型 API 抽象。
- `evals/cases.json` 为唯一用例源，实验产物进入 ignored `work/`。
- 文档采用短 AGENTS 导航、一份流程、一份审计、一份本计划；不维护第二套任务状态。
- 先建立行为基线；有歧义的规则修复等待维护者明确意图。
- 首次公开需要处理既有历史；保留本地历史，不自行重写、配置远程或推送。
