# 天文、天体物理与 AI 用语

只在涉及专业术语、缩写或数学呈现时查阅。不据中文词表改变物理定义、模型任务或项目约定。

## 查证顺序

1. 先查当前可访问的本机离线天文名词库。macOS 可使用词典.app 中已安装的天文词库，或用户提供且可以读取的离线文本。本 skill 不附带完整词库；不要假设任何本地副本存在，也不要仅凭词典目录存在声称已查到词条。
2. 本机离线资料无法访问时，使用[在线天文名词库](https://nadc.china-vo.org/astrodict/)。离线缺词、同名概念无法消歧或需要核对新术语时，也可继续查在线条目、原始论文或官方文档。
3. 没有公认中文对应或暂时无法核实时保留英文；在相关位置注明所查来源或尚未核实，不猜译。已确定的常用词无需每次查询。

macOS 词典.app 或用户离线文本的版本可能不同；应核对实际查询版本，不自动下载、升级或替换用户词典。用户限制联网或下载时遵守该范围；资料不可访问也不妨碍保留原有术语进行改写。

## 可选外部词库

- [在线查询](https://nadc.china-vo.org/astrodict/)及[开放使用约定与官方下载入口](https://nadc.china-vo.org/astrodict/article/download)：由中国天文学会天文学名词审定委员会提供，用户可按原约定自行获取。它是外部资料，不适用本 skill 的 MIT 许可；归属说明见[第三方声明](../THIRD_PARTY_NOTICES.md)。
- 使用用户已有离线文本时，先确认可访问的实际路径、版本和格式，再按词检索。2024-10-20 下载版为 UTF-8、TAB 分列，包含英文全称、缩写及中文对应；不能据此假定用户的其他版本格式相同。

按词查找，不全文加载词库。下例中的文件路径由用户实际提供的副本替换，不是 skill 内置路径：

```sh
rg -n -i -F -- 'accretion' "$ASTRODICT_PATH"
```

再读命中行的完整中英文，结合上下文排除前后缀或其他概念；中文列也可反向检索，无需另装一份汉英排序文件。`accretion` 的对应为“吸积”；检索更长词组时不能仅取这个单词的译名拼装。

使用外部词库时保留其来源与使用约定；不要修改原词条、与其他词库合并后二次发布，或将其声明为可任意商用。技能不负责下载、打包或再分发完整词库。

## 英文、缩写与同名概念

token、CNN、Transformer 等领域通行英文或缩写应保留，不机械翻译。需要帮助读者或存在缩写重名时，按输入已有信息补英文全称或注解。例如同一文档若以 GNN 分别指 Graph Neural Network 与 Gated Neural Network，应各自注明，后续使用能区分二者的称呼；原文没写全称时查论文或官方资料，不能从缩写猜架构。

同一概念用词一致。中文译名相同不代表物理量或模型相同；先核对定义，再决定如何表达。路径、配置项、字段名和既有代码标识仍原样引用。

## 数学呈现

改写文字时保留变量、单位、条件、近似号、不等号方向和符号定义。行内变量、短阈值与随句关系使用目标格式的行内数学；需要独立讨论、编号、对齐或分段的表达使用行间数学，不能遇到公式就另起一块。

支持数学的 Markdown 通常用 `$...$` 与 `$$...$$`，应核对目标渲染器；LaTeX 用 `$...$` 或 `\(...\)` 行内，`\[...\]`、equation 或 align 行间。数学关系不能整段放进 `\text{}`；它只用于公式中的短文字条件。以下是排版演示，不是研究结论或默认阈值：

- 短条件随句写：当 $x > 0$ 时，计算 $\log x$。
- 需要独立说明分段定义时可写：

$$
f(x)=\begin{cases}
x, & \text{当 } x>0,\\
0, & \text{当 } x\leq 0.
\end{cases}
$$

沿用目标文档的符号和渲染方式；排版示例不授权替换现有数学定义。
